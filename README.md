## 中文说明

Peacock 为雀音匠英文品牌名，AuraSand 为“流沙”系列英文名。

本项目用于发布 Peacock AuraSand SLIM-Z 解压推牌基础主体结构的第一版轻量开放资料包。

本次公开内容包括：3DM 基础主体结构文件、预览图、授权协议、商业使用说明、技术参考说明、免责声明和商标声明。

本项目公开的是基础主体结构资料，不是完整量产图纸包、完整加工工艺包、供应链资料、品控资料或售后判定标准。

本项目采用 3DM 作为主要开源格式，是因为 3DM 文件可以保留图纸中的文字声明、标注和说明内容；部分中性格式导出可能导致文字声明或字体信息丢失。

使用本项目资料前，请阅读 `LICENSE.md`、`COMMERCIAL_USE.md`、`TECHNICAL_NOTES.md`、`DISCLAIMER.md` 与 `TRADEMARK.md`。下载、查看、使用、复制、修改、分发或商业使用本资料，即表示已阅读、理解并同意本项目相关文件。

## English Terms

Peacock is the English brand name of 雀音匠. AuraSand is the English name of the 流沙 product series.

This project publishes the first lightweight open release package for the base structure of the Peacock AuraSand SLIM-Z fidget slider.

Included materials: 3DM base-structure file, preview image, license terms, commercial-use rules, technical notes, disclaimer, and trademark notice.

These materials disclose the base structure only. They are not a complete mass-production drawing package, manufacturing process package, supply-chain package, quality-control package, or after-sales quality standard.

This project uses 3DM as the primary open file format because it preserves the drawing notices, text labels, and embedded explanations. Some neutral-format exports may lose text notices or font information.
